# IPL Streamlit Analytics Dashboard

## Project Description

This project is an interactive IPL Data Analysis and Visualization
dashboard developed using Python and Streamlit.

The application provides:

- Login / Sign In
- About Project
- IPL Data Analysis
- Data Visualization
- Interactive filters
- KPI cards
- Data calculations
- Interactive charts

## Technologies Used

- Python
- Pandas
- Streamlit
- Matplotlib
- Plotly

## Dataset

The project uses the IPL 2008–2026 merged dataset containing
match-level information such as:

- Season
- Match Date
- City
- Venue
- Teams
- Toss Winner
- Toss Decision
- Team Scores
- Match Winner
- Winning Margin
- Player of the Match

## Dashboard Features

### Data Analysis

- Total Matches
- Total Seasons
- Total Venues
- Average Runs
- Total Match Runs
- Total Wickets
- Highest Combined Score
- Season Filter
- Team Filter
- Missing Value Analysis

### Data Visualization

- Bar Chart
- Line Chart
- Pie Chart
- Histogram
- Scatter Plot
